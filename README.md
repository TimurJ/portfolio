# portfolio

Personal portfolio site — a minimalist, static single page built with [Astro](https://astro.build) and the "Modernist" design system.

## Commands

| Command        | Action                                   |
| :------------- | :--------------------------------------- |
| `pnpm install` | Install dependencies                     |
| `pnpm dev`     | Start the dev server at `localhost:4321` |
| `pnpm build`   | Build the production site to `./dist/`   |
| `pnpm preview` | Preview the production build locally     |
| `pnpm check`   | Type-check `.astro`/`.ts` files          |
| `pnpm format`  | Format the codebase with Prettier        |

Requires Node ≥ 22.12 and pnpm (pinned via the `packageManager` field).
